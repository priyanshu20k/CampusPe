# CampusPe — AI Campus & Placement Platform

CampusPe is an interactive, modern web platform designed for India's student placement ecosystem, AI campus discovery, and employer recruitment. It bridges students, colleges, and hiring partners with real-time matching, automated resume assessment, and direct hiring pipelines.

**Vercel Deployment Link:** https://campus-pe-phi.vercel.app/

## 🚀 Features

* **Dynamic Hero & Live Matching Feeds:** Interactive cards highlighting daily student shortlist updates, recruiter verification, and instant match statistics.
* **Accredited Partners Strip:** Continuous animated marquee showcasing institutional partners including GINSERV, VTU, DST, and Startup India.
* **Opportunity Discovery Hub:** Filterable tabs for full-time placements, internships, and hackathons with verified recruiter badges, stipend/CTC indicators, and one-click applications.
* **AI Resume Scanner & ATS Scorer:** Simulated resume assessment tool providing an ATS score breakdown, identified strengths, and instant optimization feedback.
* **College Placement Automation:** Dedicated portal for academic institutions to manage campus drives, track placement statistics, and connect with top recruiters.
* **Employer Hiring Suite:** Zero-friction hiring funnel enabling recruiters to filter verified talent, shortlist candidates, and schedule interviews.
* **Interactive Mobile App Showcase:** High-fidelity phone preview carousel demonstrating the native CampusPe mobile experience across Explore, Feed, Courses, and Profile tabs.
* **App Download & Support Integration:** Quick links for Google Play and Apple App Store, alongside direct support channels including WhatsApp and phone callbacks.
* **Interactive Action Modals:** Functional popup workflows for student applications, campus demo booking, recruiter job postings, and user authentication.

## 🛠️ Tech Stack

* **Framework:** React 19
* **Bundler & Dev Server:** Vite 6
* **Styling:** Tailwind CSS v4
* **Icons:** Lucide React
* **Animations:** CSS transitions & smooth marquee keyframes

## ⚡ Getting Started

### Prerequisites
* Node.js (v18 or higher recommended)
* npm or bun

### Installation
1. Clone or download the repository.
2. Install the required dependencies:
```bash
npm install
```

### Running Locally
Start the Vite development server on port 3000:
```bash
npm run dev
```
The application will be live at `http://localhost:3000`.

### Building for Production
To create an optimized production bundle:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```
